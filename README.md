# Personal Time Capsule

A web application that lets users save personal memories and revisit them on a future date. The project is designed around the idea of preserving today's moments for tomorrow.

## Features

- **User Registration and Login** : Create an account and access your personal capsules.
- **Password Reset** : Reset your password through the password recovery feature.
- **Create a Time Capsule** : Save a title, description, personal message, and unlock date.
- **My Capsules** : View and manage your saved time capsules.
- **Date-Based Unlocking** : Future-dated capsules remain locked until their unlock date.
- **Memory Attachments** : Support for attaching memories such as images, videos, and PDFs.
- **Capsule Deletion** : Delete a capsule from your collection.

## Technologies Used

Backend: Python and Flask  
Frontend: HTML and CSS  
Database: SQLite
